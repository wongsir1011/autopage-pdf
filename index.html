自動化螢幕翻頁截圖
一鍵合併為清晰 PDF

專為個人研究、投影片筆記與畫面歸檔設計的輕量級自動化工具，支援自訂範圍、定時翻頁與高品質無損 PDF 輸出。

下載使用 查看教學

核心功能

精準範圍校準

提供互動式滑鼠定位，自動辨識左上與右下座標，僅擷取指定內容區塊。

自動排程翻頁

自訂頁數與翻頁間隔，自動模擬鍵盤操作，支援滑鼠邊角防呆緊急中止。

無損 PDF 合併

擷取完成後自動按序編排並轉檔為標準 PDF，兼具效率與畫質。

三步驟快速上手

1

定位截圖區域

開啟閱讀視窗與程式，依照提示將滑鼠移至頁面左上角與右下角記錄座標。

2

自動擷取與翻頁

設定總頁數與翻頁間隔後，程式自動執行「截圖 → 翻頁」循環。

3

輸出 PDF 文件

擷取完成後自動無損合併為單一 PDF 文件，並清理暫存圖片。

取得工具原始碼

可直接至 GitHub 取得 Python 腳本或 Clone 專案使用。
